# RPA Challenge - Dynamic Form Automation

##  Overview
This project automates the data entry process for the [RPA Challenge](https://rpachallenge.com) dynamic web form using UiPath.

## Features
- **Dynamic Field Handling:** Reliably fills out 10 rounds of forms where input field positions shift dynamically after each submission.
- **Data Integration:** Reads input data directly from the official Excel dataset (`challenge.xlsx`).
- **Demonstration:** Includes a video recording demonstrating the execution of the automation flow.

## Project Structure
- `Main.xaml`: Primary automation workflow file.
- `project.json`: UiPath project configuration and dependencies.
- `challenge.xlsx`: Source dataset for dynamic form entry.
- `RPA Challenge 1- AI automation - UI path - running demo.mp4`: Video demonstration.

## Technologies
- **UiPath Studio** (RPA Framework)
- **Excel Data Table Automation**
- **Web UI Automation**
